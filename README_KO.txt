버블 공룡 대모험 — 업그레이드 프로젝트
=====================================
Godot 4.6.3 기준. project.godot을 열어 F5로 실행합니다.

1인용 아케이드: 좌우 이동 → 점프 → 방울로 적 포획 → 포획 방울에 몸을 대서 처치.
제한 시간 내 터뜨리지 않으면 적이 탈출합니다. 모든 적을 처치하면 다음 스테이지.
10개 스테이지마다 색상/발판 배치/적 숫자와 속도가 달라집니다.
목숨 3개, 피격 후 1.8초 보호, 적 처치 100점, 10단계 완료 시 승리.
발판은 아래에서 통과해 위에 착지하는 방식입니다.

PC: A/D 또는 좌우 방향키 이동, Space/위 방향키 점프, X 방울.
터치: 왼쪽 < > 이동, 오른쪽 JUMP/BUBBLE. 여러 손가락 동시 조작 지원.
버튼 밖으로 손가락을 끌면 해당 동작이 해제됩니다.
점프/발사 버튼을 누르고 있으면 착지 후 재점프/연속 발사합니다.
P/Esc 또는 상단 PAUSE: 일시정지. M 또는 SOUND: 음악/효과음 음소거.
게임 종료 후 화면 터치 또는 Enter로 재시작.
앱 포커스를 잃으면 입력을 해제하고 일시정지하며, 복귀 후 RESUME으로 계속합니다.

배경 멜로디와 점프/발사/포획/처치/피격 효과음은 프로젝트 코드에서 합성합니다.
별도 외부 음원이나 원작 그래픽이 필요하지 않습니다.
음악과 효과음은 별도 AudioStreamPlayer를 사용합니다.

iPhone 15 Pro: 가로 방향, arm64, 1280×720 가상 해상도와 비율 유지.
개인 Mac 없이 클라우드 macOS에서 빌드하는 GitHub Actions가 포함됩니다.
